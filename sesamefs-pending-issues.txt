    Files: internal/gc/gc.go, internal/gc/store_cassandra.go

    - Cassandra 5 termina logueando estos caminos como lecturas internas tipo SELECT * ... LIMIT ... ALLOW FILTERING, aunque la app no emita ALLOW FILTERING literal
    - No conviene volver a contadores best-effort viejos: ya se retiraron por drift estructural
    - Dirección segura pendiente: sacar el recount exacto del hot path de reconcile/status y mantener snapshot por write-path con scrub/repair infrecuente
    - El cambio del worker que remueve orgs activos cuando len(items) < batchSize se mantiene: sigue siendo seguro y ataca un problema distinto (stale active orgs / empty dequeues repetidos)
    - Ver: docs/KNOWN_ISSUES.md
