1. SECURITY (Open)
=======================================

1.1 Programmatic Auth Broken (PATs/Device Flow) [P0 — BLOCKS PRODUCTION]
    File: internal/api/server.go:1141
    - `POST /api2/auth-token/` returns 401 in OIDC-only mode (TODO in code)
    - Desktop client, seaf-cli, scripts, CI pipelines cannot authenticate
    - Workaround: AUTH_DEV_MODE=true (not suitable for production)
    - Solution: Personal Access Tokens (~200 lines) or OIDC Device Flow
    - See docs/TECHNICAL-DEBT.md §6 for full analysis

1.2 GC Multi-Instance Not Safe [P0 — BLOCKS SCALING]
    File: internal/gc/gc.go:99
    - Start() launches goroutines without coordination between replicas
    - Multiple replicas = duplicate scans + race conditions on dequeue
    - Solution: env var GC_ENABLED (simple) or Cassandra LWT leader lease (robust)

1.3 Quota Period Rollover Job Missing [P0 — BLOCKS PAID USERS]
    - No code exists to reset traffic_period_usage when current_period_ends_at <= now
    - Without this, traffic quotas never roll over → paid users permanently blocked after month 1
    - Fields current_period_started_at/ends_at exist on organizations table
    - Solution: Ticker in GC or standalone job

1.4 CORS Defaults to Allow All Origins [MEDIUM]
    File: internal/api/server.go (~line 256)
    - Verified 2026-04-02: prod mode actually defaults to deny-all (correct)
    - Missing: startup WARNING when AllowedOrigins is empty in production
    - Dev mode allowing all origins is fine

1.5 Silent DB Error Swallowing in Sync [LOW]
    File: internal/api/sync.go (~line 700)
    - Block metadata write failures silently fall back to "hot" storage class
    - Fix: add slog.Warn() (5 minutes, no behavior change)

1.6 Anonymous Auth Bypass in Dev Mode [LOW - dev only]
    File: internal/api/server.go (~line 870)
    - Only affects dev mode, not production — low risk
